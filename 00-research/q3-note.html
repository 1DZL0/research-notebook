Q3: Reasoning pathways

Whether an agent’s internal states show strategies diverging before the text does.

Q3: Can the internal states of an agent show where its reasoning diverged?

Two agents running the same model on the same task end up reasoning differently. That difference is visible in what they write. The question is whether it is visible inside them first, and whether the inside view says anything the text does not.

The question, sharpened

Q2 compares two pieces of reasoning by what the model said. That works, it is cheap, and it needs no access to the model’s insides. This question asks whether opening the model up is worth the extra cost:

Does the divergence show up in the internal states before it shows up in the text?

If the answer is no, then internal states are a more expensive way of seeing something the words already showed, and this question can be closed. If the answer is yes, then the model commits to an approach before it writes anything that reveals it, and there is a whole layer the text-level view cannot reach.

Everything else on this page depends on that one result, so it is worth settling early.

Why it might be yes

Two reasons to expect the inside view to show more:

  1. A model does not always write down what actually drove its answer. If that is true, comparing what two agents wrote compares their explanations, not their reasoning.

  2. And if there is a line of work where agents pass hidden states to each other instead of text. In that setting the reasoning never becomes words at all. If systems keep moving in that direction, reading internal states stops being optional.

Working assumptions

  • Activations can be recorded from any model whose weights are available. Size limits how much can be stored and how easily it can be interpreted.
  • Two agents running the same base model produce states in the same coordinate space, so their internal states can be compared directly.
  • Agents running different models do not share a coordinate space, and comparing them needs a method built for that
  • Some part of a model’s internal state carries which approach it is taking, seprate from what it produces (shows)

Open questions

  • Does internal divergence come before textual divergence, and by how much?
  • Which states are worth recording: residual stream, attention patterns, or something learned on top of them?
  • Can two agents running different models be compared at all, or only two copies of the same one?
  • Is there anything in the internal state that says an approach is going to fail, before the failure appears in the output?

Available methods

Some tools already exist and are not specific to this question.

  • Projecting intermediate states onto the vocabulary to see what the model is leaning toward mid-computation.
  • Training small probes to test whether a given property is present in a state.
  • Sparse autoencoders for pulling apart states that mix many things at once.
  • Attention analysis for which earlier parts of the text a later part is drawing on.
  • Representational similarity methods for comparing across models that do not share a coordinate space.

Note. Thought Anchors already asks this from both sides. From the outside it rewinds to a step, runs the model again many times, and sees whether the answer changes: if it does, that step was a real decision. From the inside it blocks the model from looking back at that step and sees what breaks. Same question, once from the words and once from the machinery, which is the comparison this page is built on.

Possible investigation

Reuse the branching set-up from Q2 rather than building a new one. For each fork point, record the internal states in the run-up to it as well as the branches that follow.

Then ask three things in order:

  1. Do the internal states shortly before a fork predict which branch gets taken?
  2. Do they predict whether that branch succeeds, earlier than the text does?
  3. If yes to either, how far ahead of the words does the signal appear?

Scope note

This is the same measurement problem as Q2 with a different instrument. Q2 asks whether two pieces of reasoning are doing the same thing, judged from the output. Q3 asks the same, judged from the inside. It is deliberately the second instrument to build, because the cheap one should be shown to be insufficient before the expensive one is justified.
